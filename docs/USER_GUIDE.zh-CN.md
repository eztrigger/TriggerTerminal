# TriggerTerminal 使用说明

如果你下载的是 Mac 或 Windows 安装包，请先看[桌面安装说明](../desktop/README.md)，不需要执行下面的源码安装命令。本文中的功能操作说明同样适用于桌面版。


[English](USER_GUIDE.en.md) · [项目首页](../README.md)

TriggerTerminal 把行情、期权链和本地持仓账本放在一个界面里。你可以只用它看行情，也可以手动记账，或者读取本机 IBKR Gateway / TWS 的账户快照。

添加仓位、平仓、行权和资金变动都只是本地记录，不会向券商下单。0.1.0 包含持仓分析、期权策略分析和虚拟币资产管理。

## 1. 安装与启动

桌面安装包支持 Windows x64 和 macOS Apple Silicon。以下命令仅适用于选择从源码运行的用户。

准备 Node.js 22 或更高版本，以及随 Node.js 提供的 npm。需要连接 IBKR 时，再准备 Python 3.11 或更高版本。只用 Yahoo 行情和手动记账，可以先不安装 Python 桥接环境。

先解压源码，在终端进入包含 `package.json` 的目录。确认位置后运行：

```sh
node --version
npm --version
npm ci
npm run build
```

`npm ci` 安装锁定的依赖版本；`npm run build` 编译后台和网页。两步都成功后再启动。

打开两个终端窗口，都进入项目根目录。

**第一个窗口：启动后台。**

```sh
npm run start -w server
```

**第二个窗口：启动网页。**

```sh
npm run start -w web -- --hostname 127.0.0.1
```

浏览器打开 [http://localhost:3000](http://localhost:3000)。后台默认使用本机 4000 端口，网页使用 3000 端口。使用期间保留这两个终端；停止时分别按 `Ctrl+C`。

第一次启动后台会创建 `data/` 和本地 API 密钥，网页端会自动读取这个密钥。正常的本机使用不需要复制密钥，也不需要在浏览器里输入它。

需要 IBKR 时，在项目根目录补装：

```sh
python3 --version
python3 -m venv bridge/.venv
bridge/.venv/bin/python -m pip install -r bridge/requirements.txt
```

源码运行默认使用 `bridge/.venv/bin/python`（Windows 为 `bridge/.venv/Scripts/python.exe`），也可通过 `PYTHON_EXECUTABLE` 指定解释器。桌面安装包会自动使用内置 Python。

Mac 和 Windows 安装包的使用与构建方式见[桌面版说明](../desktop/README.md)。安装包单独发布，不包含在源码 ZIP 中。

## 2. 第一次打开

新安装没有个人账户、仓位、现金记录或历史成交。交易台默认显示一些通用行情面板和自选代码，例如 AAPL；这些是界面初始内容，不是导入的投资组合。旧版手动账本里可能看到一个空的 `Main` 容器，它也不含成交。

先在顶部选择“中文”或“English”，再决定行情源。如果暂时不连接 IBKR，选择 Yahoo Finance，并按下一节重启服务。

第一次可以按这个顺序熟悉界面：

1. 在自选列表输入一个代码并添加，点击它切换当前标的。
2. 在左侧添加“期权链”，确认页面显示的数据来源。
3. 打开“仓位与分析”，确认账户和持仓列表为空。
4. 要开始记账时，再建立自己的账户。

打开持仓页时，程序可能尝试读取本机 IBKR 账户快照。没有 Gateway 时，连接失败不妨碍手动记账；读取快照本身也不等于已将账户同步进本地持仓。

## 3. 选择行情源

顶部的“行情源”有两个选项。它控制主要行情功能，不会把新闻、财经日历等所有外部内容统一换成同一家来源。

| 功能 | API 模式 | Yahoo Finance 模式 |
| --- | --- | --- |
| 价格图表 | IBKR 历史行情 | Yahoo 历史行情 |
| 自选列表 | IBKR 推送行情 | Yahoo 定时请求 |
| 期权链 | IBKR | Yahoo |
| 持仓自动报价 | IBKR | Yahoo 支持的股票、ETF 和标准美股期权 |
| 单独的行情报价面板 | 公共行情接口及备用来源 | Yahoo |
| 顶部搜索、持仓内的标的搜索 | IBKR | 仍使用 IBKR |
| IBKR 账户快照与同步 | IBKR | 仍使用 IBKR |

**切换后要重启后台。** 下拉框旁显示“重启后生效”时，正在运行的服务仍使用旧配置。

- 网页版：在两个启动终端中按 `Ctrl+C`，然后重新运行上一节的两条启动命令，再刷新网页。
- 桌面版：点击顶部“重启”。保存好正在编辑的内容，窗口会重新加载。如果服务是从外部终端启动的，就回那个终端重启。

只按浏览器刷新按钮不会重启后台。

Yahoo 模式不需要登录 IBKR 才能加载图表和期权链，但顶部的公司名搜索仍需要 IBKR。没有连接时，可以直接在自选列表中输入代码，或点击面板标题旁的代码手动修改。加拿大股票在 Yahoo 行情中通常需要市场后缀，例如 `RY.TO`；手动持仓还应填对币种和市场。

更新频率也不代表成交频率。图表每分钟请求一次，Yahoo 的报价、自选和持仓通常约每 30 秒请求一次；后台缓存和数据商延迟仍可能让价格暂时不变。期权链单独使用手动刷新。

## 4. 连接 IBKR

源码版先完成 Python 桥接环境安装，桌面安装包已内置桥接环境。然后启动并登录你自己的 IB Gateway 或 Trader Workstation。账户密码只在 IBKR 程序里输入，TriggerTerminal 不需要保存它。

在 IBKR 程序中允许本机 Socket API 连接，使用只读 API 即可。再打开：

**仓位与分析 → 账户管理 → IBKR → 连接设置**

填写与 IBKR 程序一致的 API 端口和 Client ID，然后“保存并重连”。界面提示的常见端口如下，实际以你在 Gateway / TWS 中设置的值为准：

| 程序 | 实盘 | 模拟 |
| --- | --- | --- |
| IB Gateway | 4001 | 4002 |
| TWS | 7496 | 7497 |

Client ID 用来区分连接，不是账户号。不要与其他正在运行的 API 程序重复；期权链等功能还会使用独立连接。

保存后点击“重读 IB 账户”或账户明细中的“刷新”。能够读到资金和持仓，说明账户连接已建立；是否能读到某个合约的报价，还取决于 IBKR 提供的数据和你的行情权限。

## 5. 交易台与多窗口

左侧按钮会添加对应面板。拖动面板标题可以移动位置，拖动边角可以调整大小；右上角的关闭按钮只移除这个面板，不删除账户或持仓。

带代码的面板可以联动，也可以各看各的：

- 联动开启时，面板跟随顶部当前代码。
- 点击链条图标可解除联动。
- 点击面板标题旁的代码，输入新的代码并按 Enter，可以固定该面板的标的；Escape 取消编辑。

右上角的箭头会把面板放进独立窗口，适合拖到第二块屏幕。浏览器拦截弹窗时，需要允许当前本机页面打开窗口。独立面板有自己的代码输入框，修改它不会替换主交易台布局。

顶部“多窗口”可以打开空白交易台。这个新窗口最初没有面板，刷新当前窗口会保留它的布局；不要把这种临时窗口当作跨会话备份。需要经常复用的排列，可在左下角“布局设置”中命名保存，或设为默认。

“恢复默认布局”恢复的是当前保存的默认布局，不一定是最初安装时的排列。布局和自选保存在浏览器或桌面应用的本地存储中，不随账户数据库一起保存。

| 快捷键 | 操作 |
| --- | --- |
| `⌘K` / `Ctrl+K` | 打开代码搜索 |
| 搜索中 `↑` / `↓`，再按 Enter | 选择并打开结果 |
| 搜索中 `Shift+Enter` | 打开结果并加入自选 |
| `Alt/Option+1` | 添加图表 |
| `Alt/Option+2` | 添加行情报价 |
| `Alt/Option+3` | 添加新闻 |
| `Alt/Option+7` | 添加期权链 |
| `Alt/Option+8` | 打开仓位与分析 |

部分浏览器或键盘布局会占用组合键；遇到冲突时直接用左侧按钮。

## 6. 图表、自选和研究面板

图表支持不同时间范围、K 线 / OHLC / 折线 / 面积显示，以及均线、VWAP、布林带、RSI 和 MACD。先选择标的与范围，再打开需要的指标。图表上方会显示数据来源、K 线周期、最新 K 线时间和请求成功时间，这几个时间含义不同。

自选列表支持直接添加代码、点击切换标的、按列排序和移除代码。移除自选不会删除同一标的的持仓。表格有“恢复默认顺序”时，可用它取消当前排序。

其他面板按需添加：

| 面板 | 用途 |
| --- | --- |
| 行情报价 | 查看价格、涨跌、成交量及数据商提供的基础字段 |
| 新闻 | 阅读与当前标的相关的报道，点击标题打开原文 |
| 宏观指数 | 查看指数代理和收益率等市场数据 |
| 财经日历 | 查看数据源提供的财经事件 |
| 内部人交易 | 查看相关申报记录 |
| 财经直播 | 打开可用的外部直播来源 |
| 市场综述 | 汇总指数、涨跌股票、行业和新闻 |

外部来源未提供的数据会留空或显示错误。`—` 表示没有可用值，不应读成零。顶部“NYSE 交易中 / 已休市”按工作日和常规时段判断，没有完整处理节假日和提前收市，不能用它代替交易所日历。

## 7. 查看期权链

1. 选中标的，在左侧添加“期权链”。
2. 先检查来源标签是 IBKR 还是 Yahoo Finance。
3. 选择到期日；IBKR 存在多个合约系列时，再选择相应系列。
4. 用“行权价中心”选择参考位置，或保持“跟随标的”。
5. 选择 10 条、20 条或全部，点击“刷新价格”更新。

“10 条”指 10 档行权价，一行同时显示 Call 和 Put，不是总共只取 10 张合约。IBKR 读取全部行权价可能较慢，可以先用 10 条确认连接和报价正常。

| 字段 | 含义 |
| --- | --- |
| 最新价 / Last | 数据源返回的最近成交价，不保证仍可按此价成交 |
| 买价 / Bid、卖价 / Ask | 数据源返回的买卖报价 |
| 成交量 / Volume | 数据源返回的成交量 |
| OI | 未平仓合约数 |
| IV | 数据源返回的隐含波动率 |
| 行情 | 实时、延迟、冻结或未确认等状态 |

Yahoo 期权响应最多缓存 5 分钟，连续点击刷新可能读到同一份数据。页面的“读取于”不是成交时间。“未确认”表示没有确认行情时效类型，并不表示合约不存在。非标准调整合约不会混入这个 Yahoo 标准链。

如果没有返回指定到期日，程序会报错，不会用另一个日期的合约替代。先重新读取默认到期日，再重新选择需要的日期。

## 8. 建立账户与录入持仓

### 建立手动账户

打开“仓位与分析 → 账户管理 → 添加账户”，填写券商名称和账户昵称。账户号可以不填。按币种填写当前剩余现金，再保存。

这里的现金是**尚未投入持仓的余额**。例如账户总资产为 10,000，其中持仓市值为 6,000，剩余现金是 4,000，应填写 4,000。不要把总资产全部填成现金。

暂时不知道现金时可以留空，之后在“管理现金与记录”中设置追踪起点；不要用 0 代替未知余额。

### 先选对录入方式

“添加仓位”里有两种方式：

| 方式 | 什么时候用 | 对现金的影响 |
| --- | --- | --- |
| 期初已有持仓（不扣现金） | 开始使用时录入已经持有的资产 | 不再次扣款 |
| 新增成交（更新现金） | 记录追踪开始之后实际发生的开仓 | 按数量、价格和佣金更新现金 |

先录完期初持仓，再记后续成交和资金变动。账户发生第一笔账本事件后，不能再用期初录入补入资产，否则会把追踪基准和后续交易混在一起。

### 填写每一条资产

填写账户、仓位名称、资产类型、代码、数量、乘数和币种。数量正数为多头，负数为空头；股票可以是小数股，期权数量必须是整数。

期权还需要到期日、Call / Put 和行权价。普通股票乘数通常填 1；期权乘数要按实际合约填写。价格字段填单位价格，不是整笔成交金额。非标准合约不要直接套用 100。

“单位平均成本”和“单位估值价”可以留空；缺失时相关盈亏可能无法计算。选择 IBKR 搜索结果可以锁定具体市场和合约；没有连接时，可以手动填代码和价格。手工估值用于本地记录，不代表券商可成交报价。

期初佣金会计入成本；成本已经包含佣金时，本次佣金填 0。新增成交的单价不含本次佣金，佣金单独记入现金和已实现盈亏。

### 多腿组合和备注

同一次录入可以“添加组合腿”，为每条腿分别填写合约和数量。也可以在持仓表中把已有仓位加入策略组。策略分类和分组用于整理记录，不会生成订单。

备注按资产保存。可记录入场条件、处理计划或需要核对的事项；不要把账户密码或 API 密钥写进去。

## 9. 资金、平仓与行权

### 资金变动

在“账户管理”中找到对应账户，展开“管理现金与记录”。手动账户可以记录存款、取款、股息 / 利息和费用。选择币种，填写金额、时间和备注，再确认记账。

存款和取款改变现金，不计为交易盈利。余额录错时，使用现金更正；真实发生的入出金则应留下资金变动记录。不同币种分别记账，没有自动换汇后的统一总额。

### 平仓

在持仓行的操作中打开“平仓 / 行权”，选择平仓，填写实际数量、成交单价、佣金和时间。平仓数量填正数，程序会根据原仓位判断是卖出多头还是买回空头。可以只平一部分。

剩余仓位保留原有的估值信息，平仓价格不会替换剩余仓位的市价。记录无价值到期时，可以按实际情况以零价平仓。

### 行权或被行权

这个功能处理经确认的股票 / ETF 期权实物交割。确认合约和交割方式后，程序调整期权、股票数量及现金；反向股票按同账户、同币种的录入顺序匹配，权利金转入调整后的股票成本。

指数现金结算、调整合约和期货期权的交割不能靠这个功能自动推断。具体限制见[账本说明](HOLDINGS_LEDGER.md)。这些操作只记账，不会向 IBKR 提交行权请求。

## 10. 更正、删除和撤销

这几个按钮的效果不同，操作前先确定自己要改哪一部分。

| 操作 | 现金 | 盈亏 | 持仓 |
| --- | --- | --- | --- |
| 更正平仓成交 | 按结算差额调整 | 重算该笔已实现盈亏 | 数量更正会调整余量；有后续变动时受限 |
| 修改盈利记录 | 不变 | 更新记录金额和累计盈亏 | 不变 |
| 删除平仓记录 | 保留已结算现金 | 剔除该笔已实现盈亏 | 不恢复仓位 |
| 撤销最近记录 | 反向结算 | 移除该事件贡献 | 恢复相关数量与成本 |
| 删除未关联成交的手动仓位 | 不变 | 移除其未实现盈亏 | 删除录入 |

在持仓页的状态下拉框中选择“已平仓记录”，可以按日期、资产、账户或备注查找成交并更正。修改价格、数量或佣金会覆盖该笔手动盈利更正；只改备注不会。

“盈利记录”用于调整记录中的已实现盈亏，不能用来纠正现金余额。要撤回一笔误操作，去账户的资金与成交记录中检查“撤销最近记录”，按时间由近到远处理。

删除账户会连同本地持仓、资金和历史记录一起删除，需要输入完整账户名称确认。它不会关闭券商账户。删除前先备份，不能指望重新同步恢复手动备注和完整历史。

## 11. 同步 IBKR 持仓

在“IBKR 账户与同步”中选择账户，点击“同步到仓位页”。首次同步会建立对应的本地 IBKR 账户。需要持续更新时，可以勾选每 30 秒同步所选账户。

同步只更新 IBKR 来源的仓位；手动仓位不会被覆盖。券商快照中已经消失的仓位会进入历史列表，但程序不会猜测它的平仓价格，也不会据此生成历史成交。

同一个 IBKR 账户下可以建立独立手动仓位，但不要再手动录入快照中已有的仓位或成交。手动记录会产生单独的本地现金调整，不会自动与券商成交对账。券商同步仓位不能在这里执行本地平仓或行权。

本版本没有导入完整的券商成交和佣金历史。“已平仓记录”和累计盈亏只反映本地已记录的内容，不能当成完整的券商对账单。

## 12. 盈亏怎么计算

按账户和币种分别计算：

- 净持仓市值：各条资产带方向的市值之和。
- 未实现盈亏：按已记录成本与当前估值计算的持仓盈亏。
- 累计盈亏：已记录的已实现盈亏，加当前持仓未实现盈亏。
- 现金和入出金单独记录，不作为累计盈亏的加减项。

下面只是记账示例，数值与实际市场无关。假设开始时有 4,000 USD 现金和 10 股股票，单位成本、初始估值均为 100 USD，没有期初佣金。之后估值升到 110 USD，以 110 USD 平掉 4 股，佣金 1 USD：

| 项目 | 结果 |
| --- | --- |
| 当前现金 | 4,000 + 4 × 110 − 1 = 4,439 USD |
| 剩余股票 | 6 股 |
| 剩余市值 | 6 × 110 = 660 USD |
| 该笔已实现盈亏 | 4 × (110 − 100) − 1 = 39 USD |
| 剩余未实现盈亏 | 6 × (110 − 100) = 60 USD |
| 累计盈亏 | 39 + 60 = 99 USD |

如果成本、估值或券商历史不完整，页面会有未知值或覆盖范围提示。先补齐缺失信息，再核对结果。账本是投资记录工具，不是税务申报表。

## 13. 保存、备份和迁移

数据分两处保存：

| 位置 | 内容 |
| --- | --- |
| 项目下的 `data/` | 账户、持仓、资金、交易、备注、连接配置和本地 API 密钥 |
| 浏览器 / 桌面应用本地存储 | 布局、自选、语言及部分界面偏好 |

备份时先停止后台和网页服务，再复制整个 `data/` 文件夹到自己的安全位置。这样可以避免只复制 SQLite 主文件而漏掉尚未合并的日志。恢复时也先停止服务，保留当前目录的一份副本，再放回备份。

换电脑、换浏览器、从浏览器切到桌面窗口，或把 `localhost` 改成 `127.0.0.1`，都可能看到不同的界面偏好，因为浏览器存储不相通。持仓是否存在则取决于后台使用的数据目录。程序没有一键迁移全部浏览器布局的功能。

源码上传包不带 `data/`。之后自己使用产生的数据，也不要提交到 GitHub。更完整的存储与联网范围说明见[隐私说明](PRIVACY.md)。

## 14. 常见问题

### 网页打不开，或提示 Failed to fetch

先看两个终端是否仍在运行。网页要用 3000 端口，后台用 4000 端口。若启动日志出现 `EADDRINUSE`，说明相应端口已被占用；检查是否已经启动了另一份程序，避免同时运行两套。

### 提示连接 `127.0.0.1:4001` 失败

这是 IBKR 连接错误，不是 Yahoo 服务器地址。检查 Gateway / TWS 是否登录、API 端口是否一致，以及是否允许本机 API 连接。

如果是在期权链里出现，而且你已选择 Yahoo，先看是否还显示“重启后生效”。若是顶部搜索或账户同步报错，这些功能仍依赖 IBKR，切换 Yahoo 不会替代它们。

### Yahoo 出现 429、crumb 或暂时无数据

这是请求限制、会话获取或数据源可用性问题。等一会儿再试，不要连续点刷新。确认代码和到期日有效。程序不会在 Yahoo 期权请求失败后偷偷改连 IBKR。

### Yahoo 模式下能看图，但搜不到公司

当前搜索仍走 IBKR。没有连接时，直接把代码加入自选并点击，或编辑面板标题旁的代码。

### 持仓价格没有更新

检查资产类型、币种、合约和数据来源。Yahoo 对普通基金、期货或非标准期权等资产没有这套自动报价支持。报价失败会保留原值，不代表原值已经重新验证。可以核对后手动填写估值。

### 盈亏与券商不同

先核对数量、成本、乘数、币种、佣金和估值时间，再确认有没有把同一仓位同时手动录入和券商同步。券商完整历史没有导入，不能假定双方使用同一套记录范围。

### 记录时间无法保存

同一账户要按发生顺序记账，时间不能早于追踪起点。已有后续事件时，程序也会限制更改早期成交数量。不要仅为通过校验而随便改时间，先检查记录顺序。

### 重启按钮没有重启程序

普通浏览器中的按钮只会提示你去终端操作。停止并重新启动后台与网页即可；不需要删除 `data/`。

### 布局恢复默认了

确认是否换了浏览器、网址、桌面应用或清除了网站数据。“布局设置”里保存的布局也依赖原来的本地存储；它不在持仓数据库中。

## 15. 更新程序与重新发布

更新前备份 `data/`，停止服务。更新源码后执行 `npm ci` 和 `npm run build`，再启动。源码构建失败时先处理终端中的错误，不要清空账户数据库来尝试修复。

要分享自己的代码副本，使用发布工具导出到一个**尚不存在**的新目录：

```sh
node scripts/public-release.mjs ../TriggerTerminal-public-new
```

它会按白名单生成源码目录、ZIP 和校验清单，不复制原 Git 历史。仍需检查导出内容，尤其是以后自己新增的文件和说明。上传前参照[上传检查清单](../scripts/release/RELEASE-CHECKLIST.md)。

详细 API 开启步骤、下载链接与端口表见[项目首页](../README.md#下载与连接-ibkr)。
